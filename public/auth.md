# auth.md — luckenbach.io

## Agent audience

AI agents may read the public website, the read-only public API, and the discovery documents published by `luckenbach.io`.

## Authentication

No registration, provisioning, OAuth flow, access token, or API key is required. The site does not expose protected APIs and does not operate an OAuth authorization server.

Agents should not send credentials to this domain. Public API usage is documented at [`/api-docs.md`](/api-docs.md).

## Human contact

To contact Constantin or arrange a call, use [the public scheduling page](https://cal.com/luckenbach/quick-chat). Scheduling and any identity checks happen on that service under its own terms.
